# Smart To-Do List

A beginner-friendly student project built with **HTML, CSS, and JavaScript**.

## Features
- Add tasks with High, Medium, or Low priority
- Edit and delete tasks
- Mark tasks as completed or pending
- Filter tasks by All, Pending, or Completed
- View total, pending, and completed task counts
- Automatically save tasks in browser Local Storage
- Responsive layout for desktop and mobile screens

## How to run
1. Download and extract `smart-todo-list.zip`.
2. Open the `index.html` file in a web browser.
3. Add your first task.

No installation or server is required.

## Project files
- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — task features and Local Storage
- `README.md` — project information and instructions

## Upload to GitHub
1. Create a repository named `smart-todo-list`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` (or upload the extracted folder contents).
4. Commit the changes.

## Note
Tasks are saved in the current browser on the current device. Clearing browser data may remove saved tasks.
